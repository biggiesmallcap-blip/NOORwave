## What's new in v1.0.8

### Automix

- New (Include new music) now works without Last.fm: Automix also pulls songs from TIDAL's own mix for what is playing. With Last.fm set up, both are used.
- New music picks follow the whole session (the song you chose, the one playing, and the end of the queue) instead of only the current track.
- Each new pick says where it came from: TIDAL mix or Last.fm.
- Hovering Automix and New now explains what each does, and that New works inside Automix.

### Video

- Fullscreen videos have a heart next to Queue, so you can like a video without leaving fullscreen.
