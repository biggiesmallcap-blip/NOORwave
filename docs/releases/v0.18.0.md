## What's new in v0.18.0

### Desktop security and interface size

- Updated the desktop framework and network dependencies with security fixes. Desktop commands are restricted to the app's own local window and server address.
- Windows interface zoom works with Ctrl+mouse wheel, Ctrl+plus/minus, Ctrl+0 and the Interface size setting. Your chosen size is saved between launches.

### Settings and setup

- Settings now groups controls into Appearance, Playback, Library, Services, Remote and App, with search that opens the matching control.
- Onboarding includes an optional appearance preview. Choices stay in draft until setup completes, and unfinished choices can be recovered after a failed save.
- Last.fm and ListenBrainz connections use shared forms in setup and Settings, with clearer connection status and retry guidance.
- New listeners receive discovery setup guidance after their first successful, nonempty TIDAL library sync.

### TIDAL content preferences

- Services now offers an optional Hide AI-generated tracks setting based on TIDAL's labels. Saved library items and favorites remain available, and tracks without a label remain visible.
