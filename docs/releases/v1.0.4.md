## What's new in v1.0.4

A stability release. TIDAL sign-in recovers on its own, playback commands behave the same everywhere, and the Library page loads without a hard reload.

### TIDAL sign-in

- An expired TIDAL session now refreshes once and retries, instead of failing requests one by one. Playback, likes and playlist edits all recover the same way.
- A refresh that can't be fully confirmed no longer throws away a working login.
- The TIDAL status in Settings updates as soon as your session changes.

### Playback

- Play, next, previous, pause, seek and queue jumps now run through one path, so they stop racing each other when you press buttons quickly.
- Changing streaming quality mid-track no longer cancels the track if the new stream fails to load.
- Removing the playing song from the queue moves on to the next one cleanly.

### Library

- Top artists and the suggestion murals load on first open, and empty murals fill in while the page is open.
- Top artists are ranked by what you actually play.
- Tab pills appear at full width instead of reflowing as the page opens.
- Switching tabs or searching quickly no longer leaves a stale list on screen.

### Fixes

- Right-click menus open away from the row you clicked instead of covering it, and opening a submenu no longer closes the menu.
- Audio analysis can't be started twice, and Stop no longer leaves the scan looking like it's still running.
- Updated third-party libraries.
